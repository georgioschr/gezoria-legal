# GEZORIA Legal Center

Static GitHub Pages website for legal documents of GEZORIA applications. No build step, backend, or JavaScript required.

## Publish

1. Create a **public** GitHub repository named `gezoria-legal`.
2. Upload the **contents** of this ZIP to the repository root (not the outer folder).
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, and save.
5. Wait for Pages to deploy, then open `https://YOUR-USERNAME.github.io/gezoria-legal/`.

## Google Play Console / in-app URLs

- Privacy Policy: `https://YOUR-USERNAME.github.io/gezoria-legal/dishkeeper/privacy.html`
- Terms of Service: `https://YOUR-USERNAME.github.io/gezoria-legal/dishkeeper/terms.html`

Replace `YOUR-USERNAME` with your actual GitHub username or organization.

## Release verification

Before submitting to Google Play, verify that the text reflects the shipped APK/AAB and its actual SDKs, permissions, network traffic, storage, backups and data deletion behavior. Align Google Play's Data safety form with the implementation. This is not a legal compliance certification.

WiFi Survey legal pages are intentionally not included: those policies should be finalized when the app's actual data flows and map provider are known.
